# TypeScript engine modules a VC_TOOLING=1 build ships.
#
# A production build ships none (#921): the game runs the Rust engine only,
# and scripts/verify-engine-bundle.ts fails a production build that carries
# any src/engine/ module. A tooling build (e2e, screenshots, perf) carries the
# harnesses' hand-built tower, src/game/toolingSim.ts, which is a TypeScript
# `Simulation` the harnesses edit and inspect by hand; vite.config.ts swaps it
# for src/game/toolingSimAbsent.ts in every other build. That tower brings the
# whole TypeScript engine with it: the Simulation and the classes it holds,
# their friend modules, the save codec and migrations, the tables, and the
# TypeScript engine port (`TsEngine`) the bulletin reads a hand-built tower's
# log through.
#
# For a tooling build the verifier reads every emitted sourcemap and fails
# when the bundle carries a src/engine/ module this list does not name, or
# when a listed module no longer ships. The list only shrinks, and it goes
# when the TypeScript engine is deleted.
