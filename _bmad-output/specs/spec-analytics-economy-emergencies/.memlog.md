- (direction) Design settled in a gds design party (game architect/designer/privacy/analytics); this run only formalizes and preservation-validates, decisions not re-opened.
- (note) Story #611 follows the merged app-chrome layer (#614). Cookieless PostHog (rule D-1). Deep review is /gds-code-review (gameplay).
- (capability) CAP-1 economy_action { action; detail? }: new top-level gameplay event mirroring app_action shape (closed union, host-gated, never-throw), kept separate from app_action because gameplay not chrome. Union: demolish (detail sell|bulldoze, PER-ACTION), price_tune (session-latched once), capacity_tune (session-latched once).
- (decision) CAP-1 hooks: demolish at buildActions.ts tryRemoveUnit + transport refund path; price_tune covers rent up/down + rung pick + batch apply (value NOT captured) in editorActions.ts; capacity_tune covers add/remove car + paid shaft extend (count NOT captured) in editorActions.ts.
- (decision) CAP-1 cut as low-signal (do not re-litigate): elevator schedule edit, film policy, retail variety reroll, rung price granularity/value, rent value. Building/tool-use already covered by noteBuild/noteToolUsed, not double-covered.
- (capability) CAP-2 emergency_choice { kind; decision }: PER-OCCURRENCE user-fired at the accept/decline prompt (frameLoop.ts:117-120). kind fireRescue|bombThreat, decision accept|decline. Timeout auto-decline NOT logged (absence of a choice, not a decline).
- (capability) CAP-3 session_emergencies { fires; firesGutFloors; bombs }: emitted ONCE at session end, simulation-fired counts, mirroring session_builds/session_fps. Emitted EVEN WHEN ALL ZERO so % of sessions with a fire has its denominator. No currency amounts.
- (constraint) Engine/shell boundary: EventSystem.ts is engine (DOM/render/analytics-free), must NOT import analytics. It keeps plain integer counters (fires ignited, floors gutted to fire, bombs detonated) reset per new game; the SHELL reads them at session end and hands to GameplaySession, mirroring noteBuild being shell-called not engine-called.
- (constraint) Cookieless invariant (CAP-4): no cookie/localStorage id, per-session/cohort only never per-person, no player-authored free text (tower/unit names never sent), closed enums + integer counts only, no currency figures, host-gated, never-throw.
- (constraint) Ceiling: saveLoad.ts and main.ts are at the 500-line limit; no hook may grow them. demolish->buildActions.ts, price_tune/capacity_tune->editorActions.ts, emergency_choice->frameLoop.ts, session_emergencies accumulator in GameplaySession fed by engine counters.
- (note) Non-goals / absent systems: no loan/bankruptcy/game-over to hook (debt is just negative sim.money, no user gesture); buried treasure is a sim windfall on a user dig, left alone; rent/income and maintenance are simulation-fired (not user gestures), out of scope; player-authored names never sent.
- (decision) Acceptance criteria are vitest-testable: host-gate (nothing off a deployed host), latch (price_tune/capacity_tune once per session, reset clears), per-action vs latched (demolish each time), emit-zero (session_emergencies fires even at all-zero), timeout-not-logged (auto-decline emits nothing), engine-stays-analytics-free (EventSystem imports no analytics).
- (note) Dashboard follow-up (tooling): four tiles: economy_action by action; demolish sub-broken by detail (sell vs bulldoze); emergency_choice as kind x decision 2x2; session_emergencies -> % of sessions with a fire + avg floors gutted when one happens. Each carries the cookieless per-session/cohort caveat in words.

- (event) Self-validate Pass 2 (preservation): PASS. All load-bearing decision-log claims landed in SPEC.md or event-catalog.md companion; no wrapper-only drops. One open question logged (dashboard-tiles sequencing).
- (event) Spec finalized: SPEC.md + event-catalog.md companion derived; project-context.md adopted.
- (decision) Renamed session_emergencies field firesGutFloors -> firesGutRooms for accuracy: the engine's gut() tally increments per ROOM at the fire-caused gut sites, not per distinct floor, so the honest name is firesGutRooms. Implemented as firesGutRooms across code/tests/dashboard.
- (decision) analytics.ts crossed the 500-line ceiling with the new surface; split into analyticsCore.ts (vocabulary + trackEvent + common props) and analyticsActions.ts (free trackers + latches), analytics.ts keeps GameplaySession and re-exports both, so no other file's imports change.
- (decision) Simulation.ts is exactly at the 500 ceiling, so no emergencyCounts delegator was added; the shell reads the public EventSystem.counts getter via app.sim.events.counts in frameLoop. Keeps engine analytics-free and Simulation at ceiling.
- (event) gds-code-review round 1 (Blind + Edge Case + Acceptance; Copilot/Codex down). One PATCH: session_emergencies latched at the first tab-hide (visibilitychange), locking a zero before late-igniting fires and biasing % of sessions with a fire toward zero.
- (decision) PATCH fix: session_emergencies now emits only on the terminal pagehide (end(isFinal=true)); mid-session visibilitychange:hidden ends the session but does not latch it, so a late fire is captured. Sessions whose pagehide never fires (mobile hard-kill) drop from both numerator and denominator, keeping the rate unbiased. Added a late-fire regression test.
