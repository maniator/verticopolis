- (direction) Owner asked a 5-agent party (UX, visual/craft, game design, architecture, dev) to design ruleset reachability before spec'ing; party consensus recorded below.
- (capability) CAP-1 single canonical comparison: extract the Classic-vs-Modern body from help.ts into src/ui/templates/compare.ts (compareTemplate); every surface imports it. Success: help.ts renders it inside the unchanged Classic-vs-Modern <details> and help.test.ts drift guard passes with NO edits.
- (capability) CAP-2 active-mode label in-game: a Tower-panel badge reads 'This tower: Classic'/'This tower: Modern' from the live mode. Success: badge reflects ui.cb.getMode()/sim.mode, set from uiStatus after setTowerName, updates on adoptSim, no-ops when unchanged.
- (capability) CAP-3 reach the comparison in-game: clicking the mode badge opens a Compare modal. Success: uiDialogs.showCompare opens compareModalTemplate (h2 + compareTemplate + close) via the single #modal; closes cleanly.
- (capability) CAP-4 founding expand-in-place: a COLLAPSED <details class='nt-compare well'> under the two mode cards reveals compareTemplate inline. Success: newTower renders it collapsed, radio state untouched (one DOM box), no second surface, no newTowerModal wiring change.
- (decision) Reachability is the primary value (game designer): a returning player cannot tell which rule-set the active tower runs, nor look up what Modern does; CAP-2/CAP-3 close that. Founding (CAP-4) is secondary clarity.
- (constraint) In-app only: reuse the single reused #modal (UI.ts openModalTemplate) and lit-html. No standalone HTML page, no client-side router, no Vite input / Workbox precache / Vercel change.
- (constraint) No modal stacking and no drawer: showModal() is browser top-layer, so a drawer renders behind the backdrop, and a second dialog occludes the first on mobile and compounds the backdrop; both fail. Founding uses inline <details> only.
- (constraint) compareTemplate is the ONLY copy of the comparison prose. help.test.ts (RULE_TO_HELP map + copy-sync + uniqueness, found via sectionBySummary('Classic vs Modern')) must pass UNEDITED because compareTemplate renders inside that same section.
- (constraint) Parity-pride: no 'Modern adds N' count on the founding screen; frame Classic as the faithful reference build, never as fewer features. Keep the existing 3-feature 'Modern adds' teaser.
- (constraint) Do NOT render mode inside #tower-stats (lit one-renderer invariant); the mode badge is a separate element. setMode updates label/class only when changed (no per-pump cost).
- (constraint) House style: American English, no em-dashes, no marketing words, no 'X, not Y' pattern. Minor version bump (player-facing). Review lane /bmad-code-review. Do not touch GameRules/engine.
- (decision) Rejected standalone /help.html: duplicates canonical prose (drift), needs a Vite input + Workbox precache entry + Vercel navigateFallback carve-out, near-zero SEO/share value for a founded-tower reference.
- (decision) Rejected client-side router: one canvas view, nothing to route; a hash route is the lightest future deep-link but is not needed now.
