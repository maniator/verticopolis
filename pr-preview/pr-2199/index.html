The simulation behind the tower building game. Every rule, price, command, save format and gameplay event, ready for your own frontend.

Use it from JavaScriptUse it from RustRust API reference

JavaScript package

The WebAssembly build as @maniator/verticopolis-engine, for Node and the browser. Install and call it.

Rust crate

The verticopolis-engine crate, linked as a plain Rust library. Add it to a host, then read the host API guide.

Conformance suite

Scripted games with the state hash pinned at each checkpoint. Prove your host runs the real simulation.

What changed

Each engine release is tagged engine-v<version>. Read the changelog before you move your pin.

Your code owns everything a player sees and hears. The engine owns what happens in the tower. Frontends may differ; simulations may not.
